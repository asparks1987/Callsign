# Alpha v1 Family Completion Checklist

This checklist applies only after `v1.0`, `v1.1`, `v1.2`, and `v1.3` each pass their own gate.

- [ ] `v1.0`: install, enroll, wake, identity, overlay, app launch.
- [ ] `v1.1`: visible dictation and safe transfer.
- [ ] `v1.2`: bounded browser navigation and external-side-effect defenses.
- [ ] `v1.3`: policy-gated system/file workflows.
- [ ] Typed automation contracts.
- [ ] Policy engine and risk matrix.
- [ ] Redacted audit logging.
- [ ] Supported Windows matrix.
- [ ] WSL/Linux support level documented.
- [ ] Privacy controls and deletion.
- [ ] Installer/update direction.
- [ ] Dependency/model provenance.
- [ ] Complete clean-machine evidence.
- [ ] No Alpha feature paywall before the documented boundary.
