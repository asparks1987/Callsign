# Documentation Review Checklist

- [ ] Canon precedence respected.
- [ ] Current, Target, and Deferred are explicit.
- [ ] Correct release named.
- [ ] Identity assurance is not overstated.
- [ ] Safety/privacy impact included.
- [ ] Stop/cancel/failure behavior included.
- [ ] Commands verified against current checkout.
- [ ] Examples are labeled.
- [ ] No duplicate canonical checklist.
- [ ] Internal links resolve.
- [ ] Schemas/examples match.
- [ ] Generated site regenerated.
- [ ] No sensitive/private content.
- [ ] Status labels have evidence.
- [ ] Public claims match release gate.
