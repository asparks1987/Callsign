# Burndown Reference

The canonical, dependency-linked Callsign burndown lives at repository root:

- [../../burndown.md](../../burndown.md)

This reference page exists for the generated documentation site and must not become a second source of task status.

## Status integrity

- Imported existing labels use `Documented done` or `Documented in progress`.
- `Verified` requires current automated or human evidence.
- Percent complete is not a release claim.
- Exit criteria, not raw task count, decide readiness.
