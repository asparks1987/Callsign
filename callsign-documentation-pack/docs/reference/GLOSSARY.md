# Glossary

**Active profile** — The one local profile used for the next voice session.

**Alpha v1** — The release family `v1.0` through `v1.3`, not a single readiness gate.

**Approval** — Specific, time-bounded user authorization for one described consequence.

**Audit event** — Redacted local record of a safety-relevant decision or action.

**Callsign** — The product name, wake phrase, and a user-selected profile phrase; context must make the meaning clear.

**Command capture** — Post-identity audio/transcription window for one supported intent.

**Current** — Present and supported according to current evidence.

**Documented done** — Existing docs say complete; this pack did not rerun evidence.

**Identity gate** — Alpha session gate using active-profile callsign/voice signals. Not OS authentication.

**MCP server** — Future local typed automation capability server, stdio by default.

**Observation data** — Window titles, UI trees/text, screenshots, clipboard, paths, transcripts, audio, and related context; sensitive by default.

**Policy engine** — Deterministic authorization component outside the model and tool adapter.

**Target** — Accepted planned architecture or behavior.

**Deferred** — Not part of current release scope.

**Verification** — Postcondition check establishing what actually happened.

**Verified** — Current evidence meets the task's acceptance criteria.

**Visible action** — Action whose active state, target, and result are understandable to the user.

**Wake event** — Detector output that transitions from idle; transcript text is not a wake event.

**WSL support** — Curated typed operations that may interact with WSL; never shorthand for arbitrary shell.
