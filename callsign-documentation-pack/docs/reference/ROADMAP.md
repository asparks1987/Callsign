# Roadmap

Roadmap order follows risk reduction: prove the narrow installed loop, then visible text/browser/file workflows, then policy-gated automation.

## Foundation — current

- Canon and status reconciliation.
- Clean build/install.
- Local profile and enrollment.
- Service/runtime health.
- Wake detector and session state.
- Overlay/readout.
- Visible app launch.
- Test and release evidence.

## `v1.0 alpha`

Exit with one excellent installed workflow:

```text
install -> enroll -> wake -> identity -> overlay -> open app -> verify -> stop
```

No later feature compensates for a broken core loop.

## `v1.1 alpha`

- Visible dictation.
- Explicit transfer.
- Sensitive-target blocking.
- Provider disclosure.
- Accessibility and error recovery.

## `v1.2 alpha`

- URL/search normalization.
- Visible navigation.
- Browser adapter boundary.
- Prompt-injection defenses.
- External-side-effect blocking.
- Download safety.

## `v1.3 alpha`

- Policy engine.
- Typed automation tools.
- UI Automation-first adapters.
- Explorer-backed name/path search.
- Approved roots.
- Local audit.
- Curated Windows/WSL/Linux capabilities.
- No arbitrary shell.

## Beta foundation

- Signed artifacts.
- Supported OS/architecture matrix.
- Update and rollback.
- Privacy controls and diagnostic export.
- Formal security review.
- Reliable CI and artifact promotion.
- Schema/config migration guarantees.
- Support and vulnerability channels.
- Hardened authenticated local IPC.
- Optional local/cloud provider contract.
- Transparent packaging and licensing.

## Deferred until separately accepted

- Unattended workflows.
- Remote control.
- Broad record/replay.
- External submissions.
- Software installation.
- Admin/security changes.
- Credential-adjacent automation.
- Mobile companion.
- Cloud profile synchronization.
- Strong biometric-authentication claims.
