Say Callsign. Launch the app. Stay in control.

Callsign is a voice-driven desktop assistant for Windows. The alpha focuses on the visible workflow: create an account, train your voice, say your callsign, and launch installed apps through the Start menu.

See how it works Read the docs

How It Works

Create an account

Set up a profile with your callsign and the details Callsign needs to recognize you.

Train your voice

Record a few samples so the assistant knows when the right person is speaking.

Say the wake word

Speak Callsign, then say your callsign to unlock the command window.

Launch the app

Ask for an installed app by name and Callsign opens it through a visible Start menu flow.

Magic With Manners

Visible by design

Nothing starts unless the user sees what is happening and can stop it.

Local first

The alpha keeps profile data and enrollment state on the device by default.

Easy to explain

The product promise is simple: say the word, confirm identity, launch the app.

Open source core

The base desktop experience stays free, with freemium options reserved for later.

Open Source and Freemium

Callsign is being built as an open source desktop assistant with a freemium future. The free core should remain useful on its own, while any premium offering must not break the local-first experience or hide the basic workflow behind a subscription.
