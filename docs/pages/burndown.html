﻿# Burndown

This page mirrors the root burndown.md canon for generated docs.

Alpha v1 is a release line. v1.0 alpha is the first public MVP: background service wake detection, identity verification, animated wake overlay with live text readout, and visible Start menu app launch.

The full Alpha v1 line is the path to Windows Voice Access parity:

  • v1.0 alpha: wake, identity, overlay, live readout, and Start menu app launch.
  • v1.1 alpha: dictation with visible review.
  • v1.2 alpha: browser control.
  • v1.3 alpha: system control and Explorer-backed file search.

All Alpha v1 features are free and remain free until at least beta.
